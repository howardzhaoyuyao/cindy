Worker 平铺标签：拖拽排序并记住顺序

以下为真实 WorkerListToolbar 组件的 Electron 截图，使用模拟数据。实现在独立分支中开发，此预览用于 PR 审阅。

  • 拖动标签调整顺序；也可聚焦标签后按 Alt + ← / →。
  • 按账号、任务所在电脑和协同任务分别记忆顺序，重开后恢复。
  • 新 Worker 排在末尾，移除后其余标签保持相对顺序。
  • 拖动不切换当前 Worker；下拉列表沿用相同顺序。
  • 顺序保存在当前客户端，不同步到其他客户端，不改变执行顺序。
